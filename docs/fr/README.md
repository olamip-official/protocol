## Introduction

Le **Protocole Ouvert de Langage Aligné et Interprétable par Machine (OLAMIP)** définit un format de fichier ouvert et interopérable permettant de représenter des données linguistiques, morphologiques et phonologiques de manière structurée et lisible par les machines.

Ce dépôt contient :

- Documentation lisible par l’humain (`/docs`)
- Schémas lisibles par machine (`/specs`)
- Fichiers OLAMIP d’exemple (`/examples`)
- Workflows d’intégration continue (`/.github/workflows`)

La spécification du protocole et sa documentation (`/specs`, `/docs`) sont publiées sous la licence  
**Creative Commons Attribution–NoDerivatives 4.0 International**.

Cette licence autorise l’utilisation libre et commerciale, mais **interdit la distribution de versions modifiées** de la spécification.
