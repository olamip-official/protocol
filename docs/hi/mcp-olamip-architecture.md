# परिचय

यह दस्तावेज़ बताता है कि Model Context Protocol (MCP) और OLAMIP / OLAMIP‑DELTA मिलकर कैसे एकीकृत, मशीन‑इंटरप्रिटेबल कंटेंट डिलीवरी आर्किटेक्चर बनाते हैं, जो AI सिस्टम के लिए उपयुक्त है। यह बड़े‑स्तर की कंटेंट साइटों, डॉक्यूमेंटेशन सिस्टम और एंटरप्राइज़ वेब इन्फ्रास्ट्रक्चर पर काम करने वाले वेबमास्टर्स, तकनीकी SEO और डेवलपर्स के लिए बनाया गया है।

---

# 1. अवधारणात्मक अवलोकन

MCP और OLAMIP की भूमिकाएँ:

- **OLAMIP**: वेबसाइट की सेमांटिक संरचना, सारांश, मेटाडेटा और नीतियाँ प्रदान करता है।  
- **OLAMIP‑DELTA**: दैनिक या रोलिंग इनक्रिमेंटल अपडेट प्रदान करता है।  
- **MCP**: AI सिस्टम को मानकीकृत तरीके से OLAMIP डेटा अनुरोध और उपभोग करने की अनुमति देता है।

कुल पाइपलाइन:

```
Website → OLAMIP → OLAMIP‑DELTA → MCP Tools → AI Systems / RAG Pipelines
```

# 3. OLAMIP: सेमांटिक स्नैपशॉट लेयर

OLAMIP (`olamip.json`) वेबसाइट का पूर्ण, मशीन‑रीडेबल सेमांटिक प्रतिनिधित्व है।

इसमें शामिल है:

- साइट पहचान  
- कंटेंट हायरार्की  
- LLM‑अनुकूल सारांश  
- कैनोनिकल URL  
- टैग, भाषा, प्राथमिकता  
- इनजेशन नीतियाँ  

## 3.1 मुख्य ऑब्जेक्ट

| ऑब्जेक्ट     | उद्देश्य                           |
|--------------|------------------------------------|
| Identity     | साइट की पहचान जानकारी              |
| Section      | संबंधित कंटेंट का समूह             |
| Subsection   | नेस्टेड समूह (असीम गहराई)         |
| Entry        | अंतिम कंटेंट आइटम (पेज/प्रोडक्ट)  |

## 3.2 OLAMIP क्यों महत्वपूर्ण है

- LLM की गलत व्याख्या कम करता है  
- संरचित सारांश प्रदान करता है  
- AI‑अनुकूल कंटेंट प्राथमिकता सक्षम करता है  
- बहुभाषी साइटों का समर्थन करता है  
- स्पष्ट इनजेशन नियंत्रण देता है  

---

# 4. OLAMIP‑DELTA: इनक्रिमेंटल अपडेट लेयर

`olamip-delta.json` दैनिक या रोलिंग अपडेट प्रदान करता है।

## 4.1 डेल्टा ऑपरेशन

| ऑपरेशन | अर्थ                         |
|--------|------------------------------|
| added  | नए एंट्री या सेक्शन         |
| updated| आंशिक या पूर्ण अपडेट        |
| removed| कैनोनिकल URL के आधार पर हटाना |

## 4.2 डेल्टा संरचना

```json
{
  "date": "YYYY-MM-DD",
  "added": [...],
  "updated": [...],
  "removed": [...]
}
```

## 4.3 रोलिंग विंडो बनाम वर्ज़नड डेल्टा

| मोड            | विवरण                               | उपयुक्त उपयोग        |
|----------------|--------------------------------------|-----------------------|
| रोलिंग विंडो   | पिछले N दिनों के अपडेट एक फ़ाइल में | अधिकांश साइटें        |
| वर्ज़नड डेल्टा | प्रति दिन एक फ़ाइल                  | उच्च‑वॉल्यूम साइटें   |

## 4.4 पहचान नियम

- URL कैनोनिकल पहचानकर्ता है  
- URL बदलने पर remove + add आवश्यक  
- सेक्शन हटाने पर उसके सभी चाइल्ड हटते हैं

# 5. MCP: रिट्रीवल और इंटीग्रेशन लेयर

MCP वह रनटाइम इंटरफ़ेस है जिसके माध्यम से AI सिस्टम OLAMIP डेटा अनुरोध करता है।

## 5.1 MCP की आवश्यकता क्यों है

MCP के बिना AI सिस्टम को:

- साइट क्रॉल करनी पड़ती है  
- HTML पार्स करना पड़ता है  
- संरचना अनुमान लगानी पड़ती है  
- अर्थ का अनुमान लगाना पड़ता है  

MCP के साथ:

- `olamip.json` सीधे प्राप्त किया जा सकता है  
- `olamip-delta.json` सीधे प्राप्त किया जा सकता है  
- विशिष्ट सेक्शन/एंट्री प्राप्त की जा सकती है  
- अपडेट ऑन‑डिमांड मिलते हैं  
- RAG में स्थिर इंटीग्रेशन संभव है  

---

# 5.2 MCP टूल आर्किटेक्चर

⚠️ **महत्वपूर्ण: MCP में OLAMIP के लिए कोई बिल्ट‑इन टूल नहीं है।**  
नीचे दिए गए टूल **उदाहरण** हैं, मानक नहीं:

- `get_olamip_snapshot`  
- `get_olamip_delta`  
- `resolve_url`  
- `list_sections`  
- `get_entry`  

ये नाम LLM के लिए आसानी से समझने योग्य हैं।

## 5.3.3 चरण‑दर‑चरण इम्प्लीमेंटेशन गाइड

### चरण 1 — टूल परिभाषित करें  
### चरण 2 — हैंडलर फ़ंक्शन लिखें  
### चरण 3 — टूल रजिस्टर करें  
### चरण 4 — MCP सर्वर डिप्लॉय करें  
### चरण 5 — AI टूल स्वतः खोज लेता है  

## 5.3.4 यह आर्किटेक्चर क्यों महत्वपूर्ण है

OLAMIP AI को बिना क्रॉल किए वेबसाइट की संरचना समझने देता है।  
MCP आवश्यकता पड़ने पर पूर्ण HTML प्राप्त करने देता है।

लाभ:

- ब्लाइंड क्रॉलिंग नहीं  
- अर्थ समझने के लिए स्क्रैपिंग नहीं  
- अनुमान नहीं  
- नकली URL नहीं  
- पूर्ण HTML — केवल आवश्यकता पर  

**यह सुनिश्चित करता है कि AI सिस्टम साइट को सटीक रूप से समझ सके और आवश्यकता पड़ने पर पूर्ण कंटेंट प्राप्त कर सके। यही AI‑रेडी वेब की नींव है।**

# 9. निष्कर्ष

MCP और OLAMIP मिलकर एक भविष्य‑उन्मुख, AI‑अनुकूल कंटेंट डिलीवरी आर्किटेक्चर बनाते हैं।  
OLAMIP संरचना देता है; OLAMIP‑DELTA अपडेट देता है; MCP रनटाइम इंटरफ़ेस देता है।  
परिणाम: AI सिस्टम बिना क्रॉल किए सटीक रूप से कंटेंट समझ, इंडेक्स और रिट्रीव कर सकता है।
