# OLAMIP – हिंदी में प्रलेखन

*कॉपीराइट © 2025 राल्फ गोंजालेज – https://olamip.org*

ओपन लैंग्वेज-अलाइंड मशीन-इंटरप्रिटेबल प्रोटोकॉल (OLAMIP) भाषाई, रूपात्मक (morphological) और ध्वन्यात्मक (phonological) डेटा को एक संरचित, मशीन-पठनीय तरीके से प्रस्तुत करने के लिए एक खुला, इंटरऑपरेबल फ़ाइल स्वरूप परिभाषित करता है।

इस रिपॉजिटरी में शामिल हैं:

- मानव-पठनीय दस्तावेज़ (`/docs`)  
- मशीन-पठनीय स्कीमा (`/specs`)  
- उदाहरण OLAMIP फ़ाइलें (`/examples`)  
- निरंतर एकीकरण (Continuous integration) वर्कफ़्लो (`/.github/workflows`)  

## शुरू करना (Getting Started)

उच्च-स्तरीय परिचय के लिए `docs/overview.md` देखें।
