## مقدمة

يعرّف **البروتوكول المفتوح للّغة المحاذية والقابلة للتفسير آليًا (OLAMIP)** تنسيقًا مفتوحًا وقابلًا للتشغيل البيني لتمثيل البيانات اللغوية والصرفية والصوتية بطريقة منظمة وقابلة للمعالجة من قبل الآلات.

يحتوي هذا المستودع على:

- وثائق مخصّصة للقراءة البشرية (`/docs`)
- مخططات قابلة للقراءة الآلية (`/specs`)
- ملفات OLAMIP نموذجية (`/examples`)
- سير عمل التكامل المستمر (`/.github/workflows`)
