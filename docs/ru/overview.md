# Обзор OLAMIP

*Copyright © 2025 Ralph Gonzalez – https://olamip.org*

## Open Language‑Aligned Machine‑Interpretable Protocol

OLAMIP — это открытый стандарт, который позволяет сайтам ясно и намеренно взаимодействовать с системами ИИ. Вместо того чтобы заставлять большие языковые модели (LLMs) угадывать смысл по шумному HTML, CSS и JavaScript, OLAMIP предоставляет чистое, структурированное, машиночитаемое представление наиболее важного контента вашего сайта.

Этот документ даёт общее представление о назначении OLAMIP, его философии, формате файла и модели обновлений.

---

## 1. Зачем был создан OLAMIP

Современные сайты создаются для браузеров, а не для ИИ. В результате LLM испытывают трудности с:

- HTML со сложной версткой  
- Контентом, рендеримым JavaScript  
- Навигационными меню, рекламой и служебным текстом  
- Дублирующимися или нерелевантными страницами  

LLM *уже* сканируют ваш сайт, но часто неверно его интерпретируют. OLAMIP решает эту проблему, предоставляя AI-системам именно то, что им нужно:

- Лёгкий JSON-файл (`/olamip.json`)  
- Чистые, отобранные человеком сводки  
- Структурированные метаданные  
- Канонические URL  
- Чёткую иерархию разделов, подразделов и записей  

Внедряя OLAMIP, вы берёте под контроль то, как ИИ понимает и представляет ваш контент.

---

## 2. Основная философия: удобно для людей + удобно для машин

OLAMIP разработан как мост общения между людьми и ИИ. Каждая часть протокола должна быть:

| Principle | Human‑Friendly | Machine‑Friendly |
|-----------|----------------|------------------|
| File Format | Легко писать и проверять | Строгий, предсказуемый JSON |
| Field Names | Интуитивные и самопоясняющие | В нижнем регистре, совместимые со schema |
| Summaries | Ясный, соответствующий бренду язык | Краткий, фактический, семантически насыщенный |
| Priority System | Простые метки (`"high"`, `"medium"`, `"low"`) | Можно сопоставить с весами ранжирования |
| Documentation | Руководства простым языком | JSON schemas, правила валидации |
| Tooling | Генераторы, плагины CMS | CLI-инструменты, парсеры, тестовые наборы |

- **Для людей:** OLAMIP должен быть прост в использовании без глубоких технических знаний.  
- **Для машин:** OLAMIP должен быть структурированным, предсказуемым и однозначным.

## 3. Файл OLAMIP (`/olamip.json`)

Файл OLAMIP — это структурированный JSON-документ, размещённый по адресу:

`https://yourdomain.com/olamip.json`

Он содержит:

- `protocol` — должно быть `"OLAMIP"`  
- `version` — версия протокола  
- `identity` — кто вы  
- `content` — структурированная иерархия вашего сайта  
- `metadata` — язык, дата последнего обновления и другие глобальные поля  

### 3.1 Теги обнаружения

Чтобы AI-системы могли надёжно находить ваш файл OLAMIP, включите оба элемента:

```html
//yourdomain.com/olamip.json">
<meta name="olamip-location" content="https://yourdomain.com/olamip.json">
```

Использование обоих вариантов даёт резервирование, совместимость и устойчивость к будущим изменениям.

## 4. Структура файла

### 4.1 Объект Identity

Описывает сайт или организацию:

- `name` — обязательно  
- `type` — обязательно  
- `canonical_description` — обязательно  
- `tags` — необязательно  

### 4.2 Объект Content

Содержит:

- `overview`  
- `sections`  
- необязательные `subsections`  
- `entries` (наиболее мелкие единицы контента)  

Это поддерживает неограниченную глубину вложенности.

### 4.3 Sections

Section группирует связанный контент. Обязательные поля:

- `title`  
- `summary`  
- `url`  
- `section_type`  

Необязательные поля:

- `policy` (`"allow"` или `"forbid"`)  
- `tags`  
- `priority`  
- `published`  
- `language`  
- `subsections`  
- `entries`  

**Наследование policy:**  
Если поле опущено, policy наследуется от предков. По умолчанию — `"allow"`.

### 4.4 Entries

Entries представляют отдельные элементы контента, например:

- Статьи блога  
- Новостные материалы  
- Продукты  
- Документационные страницы  
- Исследовательские работы  
- Медиа-материалы  

Обязательные поля:

- `title`  
- `summary`  
- `url`  
- `content_type`  

Необязательные поля:

- `policy`, `tags`, `priority`, `published`, `language`, `metadata`  

URL обязательны, потому что они уникально идентифицируют контент и позволяют AI-системам проверять, дедуплицировать и связывать страницы.

## 5. Метаданные и поддержка языков

Объект metadata может включать:

```json
{
  "last_updated": "2026-01-21",
  "language": "en",
  "source_url": "https://www.yourwebsite.com/",
  "copyright": "© 2026 Example"
}
```

### Многоязычная поддержка

Язык может быть указан на уровне:

- файла  
- раздела  
- записи  

Используйте коды BCP‑47 (например, `en`, `es`, `pt-BR`, `zh-CN`).

Это помогает AI-системам:

- выбирать правильные токенизаторы  
- не смешивать языки  
- повышать точность retrieval  
- снижать галлюцинации

## 6. Теги и приоритет

### 6.1 Теги

Теги дают лёгкие семантические подсказки. Они должны быть:

- в нижнем регистре  
- из одного слова  
- ASCII  
- с дефисом для составных понятий  
- согласованными во всех записях  

Примеры:

| Concept | Valid Tag |
|---------|-----------|
| Los Angeles | `los-angeles` |
| Machine Learning | `machine-learning` |
| Data Science | `data-science` |

Теги помогают AI-системам точнее группировать, различать и извлекать контент.

### 6.2 Priority

Значения:

- `high` — флагманский контент  
- `medium` — значение по умолчанию  
- `low` — нишевый или устаревший контент  

Используйте `high` экономно (5–10% записей).

## 7. Дельта-обновления (`olamip-delta.json`)

Сайты постоянно развиваются. OLAMIP поддерживает инкрементальные обновления через дополнительный файл:

`/olamip-delta.json`

Этот файл содержит только:

- Добавленные записи  
- Обновлённые записи  
- Удалённые URL  

### 7.1 Почему дельта-обновления важны

- AI-системы остаются актуальными без повторной обработки всего файла.  
- Большие каталоги остаются управляемыми.  
- Обновления распространяются быстрее.  
- Изменения не теряются.  

### 7.2 Скользящее окно дельт (рекомендуется)

Храните все дельты за последние 7–30 дней в одном файле.  
AI-системы применяют их по порядку, чтобы оставаться синхронизированными.

### 7.3 Версионированные дельта-файлы (альтернатива)

Публикуйте отдельные файлы:

`/olamip-delta-2026-03-01.json`  
`/olamip-delta-2026-03-02.json`  
...  

Подходит для сайтов с большим объёмом контента (новости, e-commerce, документация).

### 7.4 Обнаружение

Только основной файл OLAMIP требует тегов `>` и `<meta>`.  
AI-системы автоматически ищут дельта-файлы в той же директории.

## 8. OLAMIP и традиционные sitemap

- XML Sitemap: «Вот мои страницы».  
- OLAMIP: «Вот что означает мой сайт».  

Sitemap просто перечисляют URL.  
OLAMIP предоставляет:

- сводки  
- типы контента  
- иерархию разделов  
- теги  
- метаданные  
- приоритеты  
- политики ingest  

Вместе со schema.org OLAMIP даёт AI-системам полное, отобранное человеком понимание вашего сайта.

## 9. Часто задаваемые вопросы (кратко)

### Раскрывает ли OLAMIP приватную информацию?

Нет. Он только суммирует общедоступный контент.

### Могут ли конкуренты использовать мой файл OLAMIP?

Не больше, чем они уже используют ваши публичные страницы.

### Насколько большим может быть файл OLAMIP?

Обычно 1–10 MB.  
Даже 3,000+ записей — это нормально и безопасно.

### Как часто его обновлять?

При каждом изменении контента — относитесь к нему как к sitemap для ИИ.

### Нужно ли обновлять основной файл, если используются дельты?

Да. `olamip.json` всегда является авторитетным снимком.

### LLM действительно будут это читать?

Да — в этом и состоит цель протокола.  
Проверить можно так:

```bash
curl -A "GPTBot" https://yourdomain.com/olamip.json
curl -A "ClaudeBot" https://yourdomain.com/olamip.json
curl -A "PerplexityBot" https://yourdomain.com/olamip.json
```

## 10. Краткий итог

OLAMIP превращает ваш сайт в машиноинтерпретируемую карту знаний:

- `olamip.json` — полный структурированный снимок  
- `olamip-delta.json` — инкрементальный журнал изменений  
- Sections, subsections, entries — чёткая иерархия  
- Summaries, tags, priorities — смысл, отобранный человеком  
- Теги обнаружения — надёжный ingest  
- Многоязычная поддержка — готовность к глобальному использованию  

Внедряя OLAMIP, вы обеспечиваете, чтобы AI-системы понимали ваш контент так, как вы задумали — точно, последовательно и в масштабе.
