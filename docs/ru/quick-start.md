# Быстрый старт OLAMIP

*Copyright © 2025 Ralph Gonzalez – https://olamip.org*

Этот быстрый старт показывает, как внедрить OLAMIP на сайте самым простым способом.

## 1. Создайте `olamip.json`

Разместите действительный файл `olamip.json` в корне вашего сайта:

`https://yourdomain.com/olamip.json`

Начните с небольшого чистого снимка ваших самых важных страниц.

```json
{
  "protocol": "OLAMIP",
  "version": "1.0.0",
  "identity": {
    "name": "Example Site",
    "type": "blog",
    "canonical_description": "Сайт о технологиях и обновлениях продуктов.",
    "tags": ["technology", "blog"]
  },
  "content": {
    "overview": {
      "summary": "Технологический блог о новостях продуктов, руководствах и мнениях."
    },
    "sections": [
      {
        "title": "Блог",
        "summary": "Статьи и руководства.",
        "url": "https://yourdomain.com/blog/",
        "section_type": "blog_category",
        "entries": [
          {
            "title": "Добро пожаловать в блог",
            "summary": "Введение в контент и назначение сайта.",
            "url": "https://yourdomain.com/blog/welcome/",
            "content_type": "blog_article",
            "tags": ["intro", "blog"],
            "priority": "high",
            "language": "en"
          }
        ]
      }
    ]
  },
  "metadata": {
    "last_updated": "2026-04-06",
    "language": "en",
    "source_url": "https://yourdomain.com/",
    "copyright": "© 2026 Example Site"
  }
}
```

## 2. Добавьте теги обнаружения в HTML

Добавьте эти теги в секцию `<head>` главной страницы и ключевых страниц:

```html
<link rel="olamip" href="https://yourdomain.com/olamip.json">
<meta name="olamip-location" content="https://yourdomain.com/olamip.json">
```

## 3. Делайте краткие описания

Пишите короткие фактические описания, объясняющие, о чём страница и почему она важна. Избегайте маркетингового языка, дублирующего текста и расплывчатых описаний.

Хорошо:

- "Руководство для начинающих по фотографии с длинной выдержкой."
- "Детали продукта и цены корпоративного плана."

Избегайте:

- "Лучшая страница в интернете."
- "Удивительный контент, который вам понравится."

## 4. Используйте правильные типы контента

Выбирайте наиболее специфичный `content_type`:

- `page`
- `landing_page`
- `legal_page`
- `blog_article`
- `news_article`
- `product`
- `service`
- `doc_page`
- `research_paper`
- `dataset`
- `project`
- `media_item`
- `resource`

## 5. Организуйте с помощью секций

Используйте `sections` для групп контента и `entries` для отдельных страниц. При необходимости добавляйте `subsections` для более глубокой структуры.

Пример:

- Section: Блог
- Subsection: Руководства
- Entry: Как использовать OLAMIP

## 6. Устанавливайте приоритет осознанно

Используйте:

- `high` для самых важных страниц.
- `medium` для обычных страниц.
- `low` для нишевых или старых страниц.

Не помечайте всё как `high`.

## 7. Используйте policy для контроля ingest AI

Поле `policy` говорит AI-системам, разрешено ли им обрабатывать section, subsection или entry.

- `"allow"` — явно разрешить обработку.
- `"forbid"` — запретить AI-системам обрабатывать конкретный section, subsection или entry.

Если поле `policy` опущено, OLAMIP наследует policy от ближайшего предка. Если ни один предок не определяет policy, действует `"allow"`. Для большинства сайтов можно не указывать `policy` и использовать только `"forbid"` там, где хотите пропустить контент для AI.

Примеры:

- Пропустить целую секцию:

  ```json
  {
    "title": "Устаревшие руководства",
    "summary": "Устаревший контент, не для ИИ.",
    "url": "https://yourdomain.com/old-guides/",
    "section_type": "doc_category",
    "policy": "forbid"
  }
  ```

- Пропустить одну страницу:

  ```json
  {
    "title": "Внутренняя тестовая страница",
    "summary": "Страница только для staging.",
    "url": "https://yourdomain.com/test/",
    "content_type": "page",
    "policy": "forbid"
  }
  ```

## 8. Добавьте метаданные языка

Используйте коды BCP-47, такие как:

- `en`
- `es`
- `fr`
- `de`
- `pt-BR`
- `zh-CN`

Устанавливайте язык на уровне файла, секции или записи по необходимости.

## 9. Регулярно обновляйте файл

Каждый раз, когда добавляете, изменяете или удаляете важные страницы, обновляйте `olamip.json`.

Если сайт часто меняется, также поддерживайте `olamip-delta.json` в той же директории, чтобы AI-системы оставались актуальными между полными обновлениями.

## 10. Проверяйте перед публикацией

Перед запуском убедитесь, что:

- JSON валиден.
- URL абсолютные.
- Обязательные поля присутствуют.
- Описания ясные и соответствуют рекомендуемой длине.
- Теги нормализованы и согласованы.
- Файл доступен по корневому пути.

## Минимальный чек-лист внедрения

- [ ] Создать `olamip.json`.
- [ ] Разместить в корне сайта.
- [ ] Добавить теги обнаружения в `<head>` HTML.
- [ ] Включить sections и entries для ключевого контента.
- [ ] Добавить метаданные и поля языка.
- [ ] Держать описания короткими и точными.
- [ ] Обновлять при каждом изменении сайта.
- [ ] Добавить `olamip-delta.json` для инкрементных обновлений.

## Рекомендуемая стартовая точка

Если не знаете, с чего начать, внедрите OLAMIP сначала только для главных страниц:

- Главная страница.
- Индекс блога.
- Лучшие статьи.
- Ключевые страницы продуктов или услуг.
- Важные страницы документации.

Затем расширяйте дальше.
