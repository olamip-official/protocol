# OLAMIP – বাংলা ভাষায় ডকুমেন্টেশন

*কপিরাইট © 2025 রালফ গঞ্জালেজ – https://olamip.org*

ওপেন ল্যাঙ্গুয়েজ-অ্যালাইন্ড মেশিন-ইন্টারপ্রেটেবল প্রোটোকল (OLAMIP) ভাষাগত, রূপতাত্ত্বিক (morphological) এবং ধ্বনিতাত্ত্বিক (phonological) উপাত্তকে একটি কাঠামোগত ও মেশিন-রিডেবল উপায়ে উপস্থাপন করার জন্য একটি উন্মুক্ত এবং আন্তঃকার্যকর (interoperable) ফাইল ফরম্যাট সংজ্ঞায়িত করে।

এই রিপোজিটরিতে অন্তর্ভুক্ত রয়েছে:

- মানুষের পাঠযোগ্য নথিপত্র (`/docs`)  
- মেশিন-রিডেবল স্কিমা (`/specs`)  
- উদাহরণস্বরূপ OLAMIP ফাইল (`/examples`)  
- কন্টিনিউয়াস ইন্টিগ্রেশন ওয়ার্কফ্লো (`/.github/workflows`)  

## শুরু করা (Getting Started)

একটি উচ্চ-স্তরের পরিচিতির জন্য `docs/overview.md` দেখুন।

## লাইসেন্সিং (Licensing)

OLAMIP প্রকল্পটি একটি দ্বৈত-লাইসেন্স মডেল ব্যবহার করে:

### স্পেসিফিকেশন লাইসেন্স (CC BY‑ND 4.0)

OLAMIP প্রোটোকল স্পেসিফিকেশন এবং নথিপত্র (`/specs`, `/docs`) **Creative Commons Attribution–NoDerivatives 4.0 International**-এর অধীনে লাইসেন্সপ্রাপ্ত।

এটি প্রোটোকলটির বিনামূল্যে এবং বাণিজ্যিক ব্যবহারের অনুমতি দেয়, কিন্তু স্পেসিফিকেশনের **পরিবর্তিত সংস্করণ বিতরণ করার অনুমতি দেয় না**। এটি প্রোটোকলটিকে ঐক্যবদ্ধ রাখতে সাহায্য করে এবং বিভাজন (fragmentation) রোধ করে।

### সোর্স কোড লাইসেন্স (MIT)

সমস্ত রেফারেন্স ইমপ্লিমেন্টেশন এবং টেস্ট সুইট (`/src`, `/tests`) **MIT লাইসেন্সের** অধীনে লাইসেন্সপ্রাপ্ত, যা সম্পূর্ণ পরিবর্তন, পুনঃব্যবহার এবং বাণিজ্যিক একীকরণের (integration) অনুমতি দেয়।
