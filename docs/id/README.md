## Pengantar

**Open Language‑Aligned and Machine‑Interpretable Protocol (OLAMIP)** adalah format berkas terbuka dan interoperabel yang dirancang untuk merepresentasikan data linguistik, morfologis, dan fonologis secara terstruktur serta dapat dibaca oleh mesin.

Repositori ini berisi:

- Dokumentasi yang dapat dibaca manusia (`/docs`)
- Skema yang dapat dibaca mesin (`/specs`)
- Berkas contoh OLAMIP (`/examples`)
- Alur kerja *continuous integration* (`/.github/workflows`)

## Lisensi

Proyek OLAMIP menggunakan model lisensi ganda:

### **Lisensi Spesifikasi (CC BY‑ND 4.0)**

Spesifikasi protokol dan dokumentasinya (`/specs`, `/docs`) dilisensikan di bawah  
**Creative Commons Attribution–NoDerivatives 4.0 International**.

Lisensi ini memungkinkan penggunaan bebas dan komersial, tetapi **tidak mengizinkan distribusi versi yang telah dimodifikasi**.  
Hal ini memastikan protokol tetap konsisten dan mencegah fragmentasi.

### **Lisensi Kode Sumber (MIT)**

Semua implementasi referensi dan kumpulan pengujian (`/src`, `/tests`) dirilis di bawah **Lisensi MIT**, yang memungkinkan modifikasi penuh, penggunaan ulang, dan integrasi komersial.
