## Einführung

Das **Open Language‑Aligned and Machine‑Interpretable Protocol (OLAMIP)** definiert ein offenes, interoperables Dateiformat zur strukturierten, maschinenlesbaren Darstellung linguistischer, morphologischer und phonologischer Daten.

Dieses Repository enthält:

- Menschlich lesbare Dokumentation (`/docs`)
- Maschinenlesbare Schemata (`/specs`)
- Beispiel‑OLAMIP‑Dateien (`/examples`)
- Continuous‑Integration‑Workflows (`/.github/workflows`)

## Lizenzen

Das OLAMIP‑Projekt verwendet ein Dual‑Lizenzmodell:

### **Spezifikationslizenz (CC BY‑ND 4.0)**

Die Protokollspezifikation und die zugehörige Dokumentation (`/specs`, `/docs`) stehen unter der  
**Creative Commons Attribution–NoDerivatives 4.0 International**‑Lizenz.

Diese Lizenz erlaubt freie und kommerzielle Nutzung, jedoch **keine Verbreitung veränderter Versionen** der Spezifikation.  
So bleibt das Protokoll konsistent und Fragmentierung wird vermieden.

### **Quellcodelizenz (MIT)**

Alle Referenzimplementierungen und Testpakete (`/src`, `/tests`) sind unter der **MIT‑Lizenz** veröffentlicht und erlauben vollständige Modifikation, Wiederverwendung und kommerzielle Integration.
