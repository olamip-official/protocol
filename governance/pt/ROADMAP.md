## v1.0.0 – Especificação Principal

- Finalizar o esquema JSON principal para `olamip.json`.
- Publicar uma implementação de referência mínima.
- Adicionar exemplos básicos para tipos de sites comuns (blog, e-commerce, documentação).

## v2.0.0 – Funcionalidades Aprimoradas e Ferramentas

- Expandir campos de metadados (ex.: políticas mais ricas, propriedade, procedência).
- Adicionar controles de política e ingestão mais flexíveis.
- Lançar uma ferramenta CLI de validação para verificar conformidade com esquema e formato.

## Direção Futura

- Criar um validador baseado na web para uso interativo.
- Desenvolver um explorador visual de esquemas para a especificação OLAMIP.
- Adicionar mais configurações de exemplo e integrações CMS à medida que a adoção cresce.
