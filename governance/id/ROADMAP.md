# Roadmap OLAMIP  
*Hak Cipta © 2025 Ralph Gonzalez – https://olamip.org*

## v1.0.0 – Spesifikasi Inti  
- Menyelesaikan skema JSON inti untuk `olamip.json`.  
- Menerbitkan implementasi referensi minimal.  
- Menambahkan contoh dasar untuk jenis situs web umum (blog, e‑commerce, dokumentasi).

## v2.0.0 – Fitur dan Alat yang Ditingkatkan  
- Memperluas bidang metadata (misalnya kebijakan yang lebih kaya, kepemilikan, asal‑usul konten).  
- Menambahkan kontrol kebijakan dan proses ingestion yang lebih fleksibel.  
- Merilis alat validasi CLI untuk memeriksa kepatuhan terhadap skema dan format.

## Arah Pengembangan Selanjutnya  
- Membangun validator berbasis web untuk penggunaan interaktif.  
- Mengembangkan penjelajah skema visual untuk spesifikasi OLAMIP.  
- Menambahkan lebih banyak contoh konfigurasi dan integrasi CMS seiring meningkatnya adopsi.
