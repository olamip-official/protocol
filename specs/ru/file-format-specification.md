# Спецификация формата файла OLAMIP

*Copyright © 2025 Ralph Gonzalez – https://olamip.org*

## Обзор

Файл OLAMIP (`/olamip.json`) — это структурированный JSON-документ, содержащий отобранные резюме наиболее важных страниц вашего сайта. Он разработан для удобного парсинга крупными языковыми моделями (LLM), позволяя им понимать, приоритизировать и использовать контент с ясностью, точностью и намерением.

## Расположение файла

Файл OLAMIP должен быть размещён в корне домена:

`https://yourdomain.com/olamip.json`

## Объявление расположения файла OLAMIP

Чтобы обеспечить надёжное обнаружение файла OLAMIP, разместите как `<link>`, так и `<meta>` тег в секции `<head>` вашего сайта.

### Основной способ обнаружения: `<link rel="olamip">`

- Стандартизированная практика: парсеры уже ищут ресурсы через `<link>`.
- Удобно для машин: устанавливает формальную связь с файлом OLAMIP.
- Совместимость: легко интегрируется в существующие веб-стандарты.

### Резервный способ: `<meta name="olamip-location">`

- Понятно для людей: легко добавить.
- Совместимость: некоторые инструменты предпочитают `<meta>`.
- Надёжность: служит резервом.

### Рекомендуемая реализация

```html
<link rel="olamip" href="https://yourdomain.com/olamip.json">
<meta name="olamip-location" content="https://yourdomain.com/olamip.json">
```

## Структура файла

Файл должен быть валидным JSON (UTF‑8) и содержать:

- `protocol`
- `version`
- `identity`
- `content`
- `metadata`

### Общая структура

```json
{
  "protocol": "OLAMIP",
  "version": "1.0.0",
  "identity": {},
  "content": {},
  "metadata": {}
}
```

## Объект Identity

| Поле | Тип | Обязательно | Описание |
|---|---|---:|---|
| `name` | `string` | Да | Название сайта или организации |
| `type` | `string` | Да | Тип (например, `company`, `blog`) |
| `canonical_description` | `string` | Да | Описание сайта |
| `tags` | `array<string>` | Нет | Ключевые слова |

## Объект Content

Содержит:

- `overview`
- `sections`

### Overview

| Поле | Тип | Обязательно | Описание |
|---|---|---:|---|
| `summary` | `string` | Да | Краткое описание сайта |

## Section

Раздел контента.

### Поля

| Поле | Тип | Обязательно | Описание |
|---|---|---:|---|
| `title` | `string` | Да | Название |
| `summary` | `string` | Да | Описание |
| `url` | `string` | Да | URL |
| `section_type` | `string` | Да | Тип |
| `policy` | `string` | Нет | `"allow"` или `"forbid"` |
| `entries` | `array<Entry>` | Да | Элементы |
| `subsections` | `array<Section>` | Нет | Подразделы |

## Политика

- `"allow"` — разрешено
- `"forbid"` — запрещено

По умолчанию: `"allow"`

### Наследование

1. Entry
2. Subsection
3. Section
4. По умолчанию

## Entry

Минимальная единица контента.

### Поля

| Поле | Тип | Обязательно | Описание |
|---|---|---:|---|
| `title` | `string` | Да | Заголовок |
| `summary` | `string` | Да | Описание |
| `url` | `string` | Да | URL |
| `content_type` | `string` | Да | Тип |

## Типы контента

- `page`
- `blog_article`
- `news_article`
- `product`
- `doc_page`
- `research_paper`

## Массивы

Пример:

```json
"tags": ["ai", "search", "llm"]
```

## Metadata

```json
{
  "last_updated": "2026-01-21",
  "language": "ru"
}
```

## Приоритет

- `"high"`
- `"medium"`
- `"low"`

## Многоязычность

Используйте BCP‑47:

- `ru`
- `en`
- `es`

## Валидация

- Валидный JSON
- Абсолютные URL
- Без лишних запятых

## Теги

- В нижнем регистре
- Без пробелов
- Через дефис

Пример:

- `machine-learning`
- `data-science`

## Версионирование

- Игнорировать неизвестные поля
- Использовать актуальную схему

## Семантическое соответствие

OLAMIP дополняет schema.org, карты сайта и системы индексации, обеспечивая структурированный слой, оптимизированный для ИИ.
